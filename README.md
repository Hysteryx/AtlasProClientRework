# 📺 AtlasPro Web & Desktop Client

A modern, fast, and full-featured IPTV client built specifically for the **AtlasPro** ecosystem. Powered by **Next.js**, this project delivers both a smooth media catalog browser and a high-performance integrated video player to manage your Live TV channels, Movies (VOD), and Series.

---

## ✨ Key Features

* **Full-Featured & Intuitive Browser:** A sleek interface inspired by leading streaming platforms to effortlessly browse thousands of titles.
* **Built-In Video Player:** Native support for HLS (`.m3u8`) and MPEG-TS streams with audio track switching, subtitles, and video quality selection, resolving buffering issue on the official client.
* **VOD & Series:** Detailed media pages (synopsis, cast, ratings), automatic playback resume, and seamless episode-to-episode transitions.
* **Personalized Management:** Favorites system, watch history, instant global search, and category filtering.
* **Multi-Profile / Xtream Codes:** Streamlined login using your Xtream Codes API credentials or M3U playlist URLs.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
* **Language:** TypeScript
* **Styling:** Tailwind CSS / Shadcn UI
* **Video Player:** HLS.js / Video.js (optimized for low-latency streaming)
* **State Management:** Zustand / React Query (smart caching for large catalogs)
